# Архитектура JEPA World Model — техническая спецификация

Все размерности и число параметров получены прямой инспекцией кода
(не оценки). Латентная размерность `latent_dim = 128`, вход — grayscale
кадр 64×64, действие — непрерывный вектор 2-d в диапазоне [-1, 1].

## 1. Ядро системы

### Энкодер — 689 120 параметров

Свёрточная сеть, сжимающая наблюдение в латентный вектор.

| Слой | Вход | Выход |
|---|---|---|
| Conv2d 4×4, stride 2 | 1 × 64 × 64 | 32 × 32 × 32 |
| Conv2d 4×4, stride 2 | 32 × 32 × 32 | 64 × 16 × 16 |
| Conv2d 4×4, stride 2 | 64 × 16 × 16 | 128 × 8 × 8 |
| Conv2d 4×4, stride 2 | 128 × 8 × 8 | 128 × 4 × 4 |
| Flatten + Linear | 2048 | **128** |

Активации ReLU между свёртками. Выход — без нормализации.

### Предиктор динамики

Две взаимозаменяемые реализации с общим интерфейсом:

**MLP (безпамятный) — 132 224 параметра.**
Вход `[z_t ; a_t]` (130-d) → 2 скрытых слоя по 256 → 128.
Предсказывает **дельту**: `z_{t+1} = z_t + f(z_t, a_t)`. Остаточная
формулировка стабилизирует многошаговый прогноз.

**GRU (рекуррентный) — 429 440 параметров.**
`GRUCell(130 → 256)` несёт скрытое состояние `h_t` вдоль эпизода;
голова `[h_t ; z_t]` (384-d) → 256 → 128, также остаточная.
Применяется при частичной наблюдаемости, где одного кадра недостаточно.

**Итого ядро (энкодер + MLP-предиктор): 821 344 параметра.**

### Функция потерь — VICReg (в латентном пространстве)

Пиксельный лосс не используется принципиально: модель не тратит ёмкость
на воспроизведение текстур.

```
L = 25·MSE(ẑ_{t+1}, z_{t+1})  +  25·Var-штраф  +  1·Cov-штраф
```

- **Invariance** — точность предсказания следующего латента.
- **Variance** — каждая координата латента обязана иметь std ≥ 1 по батчу;
  это защита от коллапса представлений.
- **Covariance** — декорреляция координат, против избыточности.

Обучение: AdamW, lr 3e-4, weight decay 1e-5, batch 256.

## 2. Вспомогательные модули

Все обучаются **на замороженном энкодере**, то есть не влияют на
представление и служат инструментами анализа или планирования.

| Модуль | Параметры | Назначение |
|---|---|---|
| Temporal-distance `d(z, z′)` | 131 841 | Обучаемая метрика: цель — число шагов между состояниями. Заменяет евклидово расстояние при планировании |
| Ансамбль предикторов (K=5) | 5 × 132 224 | Разброс предсказаний = эпистемическая неопределённость динамики |
| Декодер (probe) | 690 913 | 4 × ConvTranspose, латент → 64×64. Только для визуализации «снов» модели |

Симметричность метрики обеспечивается усреднением `d(a,b)` и `d(b,a)`;
выход через Softplus — гарантированно неотрицательный.

## 3. Контур планирования

Цель задаётся **изображением**, а не координатами.

1. Целевой кадр кодируется: `o_goal → z_goal`.
2. **CEM** (Cross-Entropy Method): 512 кандидатных последовательностей
   действий, 5 итераций, отбор 64 элитных, горизонт 5–15 шагов.
   Каждый кандидат прокатывается через предиктор — планирование целиком
   происходит «в воображении», без обращения к среде.
3. Стоимость: `d(z_T, z_goal)` по обученной temporal-distance метрике
   (евклидова метрика на этой задаче непригодна — см. ниже).
4. **MPC**: исполняется только первое действие, затем перепланирование
   по новому наблюдению.

## 4. Ключевые проектные решения

**Почему предсказание в латенте, а не в пикселях.** Реконструкция
заставляет модель моделировать непредсказуемые детали. JEPA-подход
предсказывает представление, что позволяет игнорировать нерелевантный шум.

**Почему обучаемая метрика вместо L2.** Экспериментально установлено:
корреляция евклидова расстояния в латенте с реальной достижимостью
составляет лишь ≈0.67, из-за чего планировщик застревал в локальных
минимумах. Обученная temporal-distance метрика поднимает корреляцию
до ≈0.86 и обеспечивает корректный обход препятствий.

**Почему GRU при частичной наблюдаемости.** При эгоцентрическом виде
позиция агента не восстановима из одного кадра. Контролируемый
эксперимент: память повышает probe R² с 0.821 до 0.898 на эгоцентрической
среде и не даёт прироста (0.997 → 0.997) на полностью наблюдаемой —
то есть выигрыш обусловлен именно памятью, а не увеличением ёмкости сети.

## 5. Валидационные метрики

| Метрика | Значение | Смысл |
|---|---|---|
| Linear probe R² | 0.999 (x и y) | Позиция агента линейно восстановима из латента |
| Нормированный action gap | до 0.94 | Предиктор реально опирается на действие |
| z-std по батчу | ≈0.99 | Коллапса представлений нет |
| Rollout MSE @10 шагов | ≈0.53 | Качество многошагового воображения |
| Корреляция неуверенности с ошибкой | ≈0.98 (multi-step) | Ансамбль калиброван |
