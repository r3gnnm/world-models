# Автономная навигация дронов без GPS: мировая модель + квантовые эксперименты

## Задача

Автономная работа дронов там, где GPS/сигнал недоступен и человек не может
управлять вручную: помещения, туннели, густой лес. Дрон должен облетать
маршрут, исследовать неизвестную территорию и обходить препятствия —
без вмешательства оператора.

## Архитектура (см. схему выше)

Система состоит из четырёх уровней. Первые три — предмет исследования,
четвёртый — обязательная, независимая от машинного обучения основа.

**1. Восприятие.** Камера и инерциальные датчики дают наблюдение.
Локализация без GPS (VIO/SLAM) — зрелая, проверенная технология, поверх
которой энкодер JEPA строит компактное латентное представление сцены.
Это не заменяет VIO/SLAM, а работает поверх него.

**2. Динамика — честное сравнение.** Здесь два кандидата на роль
предиктора будущего состояния, и оба тестируются одинаково:
- **Классический предиктор (GRU)** — уже реализован и провалидирован на
  учебном проекте: контрольный эксперимент показал прирост качества
  именно от памяти (probe R² 0.821 → 0.898 при частичной наблюдаемости,
  без прироста на полном обзоре — то есть эффект не объясняется просто
  увеличением числа параметров).
- **Квантовый резервуар (экспериментально)** — направление quantum
  reservoir computing активно развивается: недавние работы показывают
  успешное предсказание хаотической и турбулентной динамики на реальном
  квантовом железе (IBM). Прямого применения к латентным world models
  пока не описано в литературе — это честная исследовательская ниша,
  а не воспроизведение чужого результата.

Сравнение ведётся на одинаковых метриках (rollout error, probe R²),
на данных из контролируемой игрушечной среды прежде, чем переходить
к реальным сценам.

**3. Принятие решений — экспериментальная оптимизация.** Ансамбль
предикторов (уже реализован и откалиброван — корреляция неопределённости
с реальной ошибкой ≈0.98) даёт кандидатные точки для разведки с оценкой
уверенности. Выбор следующей точки — комбинаторная задача, для которой
пробуем **QUBO-оптимизацию на квантовом отжиге** — область, где у
квантовых вычислений сегодня наиболее обоснованное практическое
применение (портфельная оптимизация, риск-моделирование в финансах —
задачи со схожей комбинаторной структурой).

**4. Безопасность — не обсуждается.** Финальное решение всегда проходит
через независимые от нейросетей правила: зависание при потере
уверенности, возврат по проверенному маршруту, географические границы,
автопосадка по таймауту. Ни один из экспериментальных компонентов
(1-3) не имеет права обойти этот уровень.

## Что уже сделано (задел)

Пилотный проект на учебной среде уже дал методологию, которая напрямую
переносится:
- Мировая модель предсказывает будущее состояние по латентному
  представлению (linear probe R² = 0.999).
- Temporal-distance метрика для корректного планирования через
  препятствия (агент проходит через проём, которого не видит напрямую).
- Калиброванный ансамбль для оценки неуверенности (корреляция с реальной
  ошибкой ≈0.98).
- Контролируемые эксперименты с памятью и иерархией — та же строгая
  методология (обучено vs случайный baseline) будет применена и к
  квантовым компонентам.

## Честные ожидания

- Квантовые компоненты **не ускоряют** обучение и не гарантированно
  превосходят классические аналоги — это открытые экспериментальные
  вопросы, не обещания.
- Оба квантовых эксперимента (резервуар и QUBO) — самостоятельные,
  независимо проверяемые, с честным протоколом сравнения против
  классического baseline.
- Реалистичный срок: игрушечная среда и первые сравнения — недели;
  перенос на реалистичный симулятор — месяцы; реальные полёты — только
  после устойчивых результатов в симуляции.

## Ресурсы, которые нужны

- Доступ к квантовому железу через корейского партнёра — важно уточнить
  тип (gate-based IBM/IonQ подходит для quantum reservoir и quantum
  kernel; annealing-система нужна для QUBO-оптимизации).
- Симулятор с GPS-denied сценами (туннели, лес) для этапа 2 плана.
- Компьютерные ресурсы уровня одной GPU для классической части —
  проектом уже подтверждено, что это достаточно для содержательных
  результатов на этапе исследования.
